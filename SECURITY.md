# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Kiban, please report it responsibly.

**Do not open a public GitHub issue for security vulnerabilities.**

Instead, please report via: https://kiryokulabs.com/contact/

Include:

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

## Response Timeline

- Acknowledgment: within 48 hours
- Assessment: within 1 week
- Fix or mitigation: depends on severity

## Scope

This security policy applies to:

- The Kiban API
- The Kiban Web UI
- The CLI
- The catalog system

## Supported Versions

| Version | Supported          |
|---------|--------------------|
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Disclosure

We follow coordinated disclosure. Please do not disclose the vulnerability publicly until a fix is available.
